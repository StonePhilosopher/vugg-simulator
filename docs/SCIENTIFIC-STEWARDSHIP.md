# Scientific stewardship

The decision rule is **follow the science**. That means observed geology and
the best applicable evidence decide the model; desired game outcomes do not.

## Evidence discipline

- Separate deterministic, statistical, aspirational, and excluded locality
  claims. Do not turn a documented accessory mineral into a guaranteed seed-42
  headline merely to make a scenario look fuller.
- State validity envelopes, units, conserved pools, boundary conditions,
  uncertainty, and empirical proxies next to the mechanism that consumes them.
- Preserve negative evidence. A mineral absent from a locality contract is a
  meaningful constraint, not an inconvenience to tune away.
- Keep run seed 42 as the default commissioning seed while retaining every
  scenario's independently authored `shape_seed`.
- Make diagnosis causal: saturation, limiting inventory, temperature, pH,
  redox, substrate, competition, growth budget, and dissolution/survival must
  describe the same runtime authority.

## Change and correction process

1. Record the question and the supported envelope before editing equations.
2. Prefer primary literature, authoritative datasets, and locality-grade
   evidence. Record citations in the generated provenance system.
3. Implement one explicit mechanism and its conservation/authentication tests.
4. Compare seed-42 and multi-seed evidence as required by the claim tier.
5. Run locality exclusions and hostile review. Document residual uncertainty.
6. If a correction changes deterministic geology, bump `SIM_VERSION`, update
   `MODEL_DIGEST`, and rebake exact evidence. Do not retune runtime chemistry to
   preserve a stale expected number.

Corrections are welcomed and retained in Git, the changelog, research notes,
and the version history. Superseded evidence remains historical; it is never
presented as current.
