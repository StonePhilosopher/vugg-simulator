# Asset, LOD, audio, and art-direction contract

`release/asset-manifest.json` is the exact-byte inventory for shipped
and source/reference media. It records file size, SHA-256, delivery role, and
rights status. The current media remains development material until a human
rights review closes every `human-rights-clearance-required` entry.

## Level of detail

Scientific authority does not have a graphics-quality slider. Every run uses
the fixed 48³ Cartesian field, zero isovalue, and independent 64³ convergence
reference. Hardware quality cannot change cavity volume, chemistry addresses,
anchors, water plane, mass booking, or replay identity.

Presentation may reduce only representative geometry:

- desktop surface coatings: at most 128 instances;
- mobile-class presentation (width ≤720 CSS px or device-pixel ratio ≥2.5):
  at most 56 instances;
- both tiers render one mass-booked aggregate, so count changes never create
  extra crystals or solid volume;
- an unsupported WebGL field renderer uses the authenticated field-derived CPU
  cross-section or withholds the view. It never substitutes the old polar wall.

Any future LOD must name its presentation-only inputs, preserve exact scientific
receipts, and pass image/performance comparisons on the physical-device matrix.

## Audio mix states

| State | Music | Default gain | Other audio |
| --- | --- | ---: | --- |
| Title / New Game / Scenarios | `Vugg Simulator.mp3` | 0.25 | UI remains visually legible |
| Simulation / Creative / Library / Record Player | `salt-circuit.mp3` | 0.25 | UI remains visually legible |
| Strip View | silent | 0 | opt-in sonifier, master 0.7 |
| Music disabled | silent | 0 | scientific information remains visual/textual |

Music loops without encoding scientific state. Strip sonification maps data to
sound, but selected chips, legends, values, and event history remain available
visually; sound is never the only carrier. Human release review must measure
loudness, clipping, interruption recovery, Bluetooth/headphone behavior, screen
reader coexistence, and reduced-motion independence on real devices.

## Human-made asset briefs

1. **Mineral Library coverage.** Produce rights-cleared, color-managed images
   for the remaining minerals. Preserve real habit, aggregate scale, substrate,
   and locality context; avoid generic gem icons. Record creator/source,
   license, crop, color transform, and mineral ID.
2. **Cavity and coatings.** Art direction must make broad chalcedony, hematite,
   malachite, azurite, manganese oxide, asbestiform, microcrystalline quartz,
   and calcite layers read as continuous wall growth while retaining the
   simulator's booked coverage and stratigraphy.
3. **Brand/title.** Resolve the current title reference into an original,
   scalable human-approved composition with safe-area crops for desktop,
   portrait, landscape, icon, and store-card formats.
4. **Interface iconography.** Use labelled, high-contrast controls with 44 px
   touch targets. Icons supplement words and never replace causal diagnoses.
5. **Audio.** Clear rights or commission replacements for both music tracks;
   prepare loop points and measured masters without changing the mix-state
   contract above.

No generated manifest or AI review constitutes final human art direction,
license clearance, accessibility certification, or store approval.
